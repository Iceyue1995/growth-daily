Style guide

"Obsidian Journal" — Growth Daily's color/type system since the 2026-08-30 redesign (built from real Stitch-generated reference screens, not guessed). Kept here so any future change can be checked against a rule instead of a gut feeling.

Accent — desaturated slate blue

The app's one accent hue. Used at brand/interactive touchpoints (active nav, links, focus rings, drill blanks) and as the "done"/"current" signal in the task list and progress heatmap — a deliberate merge (2026-08-30), read apart by icon (checkmark vs. number vs. outline), not a second color. Content-correctness feedback below stays a separate set of colors; that distinction is still load-bearing.

accent2#6f80a0Solid fills — task dots, icon circles, heatmap "done" cells. Pair with accent2-fg or #eef1f7 text, not pure white.~3.7:1 — fine for icons/UI, not for body text
accent2-strong#56637dHover/pressed states; the "interview" task icon (weightier tone of the same hue, not a second color)
accent2-fg#c3d0eaAccent-colored text/labels on a dark cardon card ~11:1 ✓
accent2-weak18% washTinted backgrounds behind accent-colored blocks

Secondary — warm cream

Reserved for the primary CTA fill only (e.g. the big "Continue" button) — per the reference's own spec, "primary buttons use a Warm White fill with dark text for maximum impact." Not used anywhere else; using it more often would dilute what makes the main action stand out.

secondary#f4f1eaPrimary button fill, toast, selection popup — always paired with on-secondary text
on-secondary#1c1c18Text on top of secondary fills

Neutrals

Near-black base with two visible surface steps above it — deliberately more separated than the reference's own raw tokens, since a barely-perceptible step defeats the point of "tonal layering."

bg#0a0a0aPage background
card#1a1a1aCards, the current-task highlight
surface-2#242424Hover states, inputs, chips — one step above card
text#e5e2e1Primary reading text

Semantic feedback

Correct / needs work / recording — for content correctness only (AI grammar corrections, drill validation). Desaturated to sit quietly in this palette instead of the old bright green/amber/red, but kept as a separate color family from the accent on purpose: this is the one distinction that's still functionally load-bearing.

Usage rules

🔷Accent = interaction + completion, never content correctness. It marks what's clickable, active, or done — the separate good/warn/error family is what tells you if an answer was right or wrong.
🔠Monospace is for short UI chrome only. Labels, numbers, nav, meta counters — never paragraphs, scripts, drills, or anything read at length; monospace slows long-form reading.
✒️Serif is for the daily headline only. Source Serif 4 is the one deliberate flourish — "thought of the day" moments and card/section titles. Geist carries every paragraph, script, and drill (chosen to stay legible for a non-native reader).
◻️No pills. Corner radius is small and rectangular everywhere (2–10px); radius-full is reserved strictly for true circles and progress-bar caps, never for buttons, tags, or badges.
▬Flat, no shadows. Surfaces are told apart by background-color steps and hairline borders (var(--line)/var(--line-strong)), not drop shadows or lift-on-hover.
👁️Contrast is checked against the exact surface a color sits on, not assumed from the palette alone — see the ratios noted above.
